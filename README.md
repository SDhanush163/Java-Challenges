## About

This repository is a collection of Java coding challenges completed while exploring the language and experimenting with different programming concepts. The challenges range from simple syntax exercises to object-oriented design and data structure implementations, providing a practical way to apply core Java concepts.

Rather than focusing on a single application, the repository is organised by topic, making it easy to explore different areas of Java independently. Each folder contains standalone solutions that demonstrate a specific concept, technique, or problem-solving approach.

## Running the Challenges

Most challenges are standalone Java applications containing their own `main()` method.

| Step    | Command                       |
| ------- | ----------------------------- |
| Compile | `javac path/to/File.java`     |
| Run     | `java package.name.ClassName` |

Example:

```bash
javac src/com/BasicChallenges/C01_PositiveNegativeZero.java
java com.BasicChallenges.C01_PositiveNegativeZero
```
